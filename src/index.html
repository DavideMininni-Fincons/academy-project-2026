POSITION (relative / absolute)

The row gets a fixed height and `position: relative`, then every child is taken out of flow with `position: absolute` and placed by hand using top/left/right + a transform trick for vertical centering.

FLOAT

Elements are floated to sit in a row. Uses right or left as value for `float`. Requires a clearfix on the row and a fixed width on the text block, plus a hand-guessed margin to vertically center the button.

FLEXBOX

Uses `display: flex` and `align-items` for vertical centering, `gap` handles spacing, `flex: 1` makes the text block adapt automatically. No floats, no manual measurements.
